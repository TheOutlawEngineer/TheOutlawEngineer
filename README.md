## <span style="color:#ffaa00">Overview</span>

The **Outlaw Engineer** repository documents industrial cybersecurity concepts, field-engineering insights, and OT/ICS drift analysis.  
This project focuses on practical, real-world system behavior observed in chemical facilities, manufacturing environments, and legacy control architectures.
